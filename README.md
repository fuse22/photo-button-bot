# Photo Button Bot

Простой Telegram-бот: одна кнопка — и бот отправляет заданную фотографию.

## Как запустить

1. Получи токен у [@BotFather](https://t.me/BotFather) -> `/newbot` -> скопируй токен.
2. Положи фотографию в эту папку под именем `photo.jpg` (или задай `PHOTO_FILE_ID`).
3. Установи зависимости и запусти:

```bash
pip install -r requirements.txt
BOT_TOKEN=123456:ABC-DEF python bot.py
```

## Переменные окружения

| Переменная     | Назначение                                             | По умолчанию |
|----------------|--------------------------------------------------------|--------------|
| `BOT_TOKEN`    | Токен от @BotFather — обязателен                        | —            |
| `PHOTO_FILE_ID` | file_id фотографии (быстрее, чем файл)                  | —            |
| `PHOTO_PATH`   | Путь к файлу фотографии                                 | `photo.jpg`  |

## Деплой на Amvera (Docker)

Репозиторий содержит `Dockerfile`. В Amvera: подключить репозиторий -> указать
переменные `BOT_TOKEN` (и при желании `PHOTO_FILE_ID`) -> деплой.

## Как узнать file_id

Напиши боту любое фото, перешли его боту [@getidsbot](https://t.me/getidsbot)
или используй свой скрипт с `message.photo[-1].file_id`.
