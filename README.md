# Фото-кнопка

Простейший Telegram-бот: одна кнопка, и бот кидает заданную фотографию.

## Запуск (без деплоя, на своем компьютере)

1. Создай бота у [@BotFather](https://t.me/BotFather): `/newbot`, скопируй токен.
2. Установи зависимости:

```bash
pip install -r requirements.txt
```

3. Запусти:

```bash
BOT_TOKEN=123456:ABC python bot.py
```

4. Напиши боту `/start` и нажми кнопку.
5. Чтобы поменять фотографию - просто пришли боту новую фотографию в чат.
   Он запомнит её сам, переписывать код не нужно.

## Переменные окружения

| Переменная      | Назначение                                     | По умолчанию |
|-----------------|------------------------------------------------|--------------|
| `BOT_TOKEN`     | Токен от @BotFather - обязателен                | -            |
| `PHOTO_FILE_ID` | file_id фотографии (если задать вручную)        | -            |

Приоритет источника фото: `PHOTO_FILE_ID` -> `photo_file_id.txt` -> `photo.jpg`.

## Docker / Amvera

В репозитории лежит `Dockerfile`. Переменные `BOT_TOKEN` и `PHOTO_FILE_ID`
задаются в настройках окружения хостинга.

## Как узнать file_id

Пришли боту фотографию - бот сам сохранит file_id в `photo_file_id.txt`.
